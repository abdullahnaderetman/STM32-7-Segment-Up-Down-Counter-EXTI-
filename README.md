# STM32-7-Segment-Up-Down-Counter-EXTI-
This project is an embedded application for an STM32 microcontroller that controls a single-digit 7-segment display (0-9) using two push-buttons. Unlike polling-based approaches, this project utilizes the External Interrupt (EXTI) peripheral. One button increments the counter, while the other decrements it. Using hardware interrupts.
